Create special events (tastings, concerts, private dinners) and list them across your venues.

## List events

Filter by venue, date, or status:

```bash
curl "https://api.kdllc.com/v1/events?venue_id=venue_4f8a2c1e&status=published" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Tip>
  Use `date_from` and `date_to` to scope results, for example `?date_from=2024-03-01&date_to=2024-03-31`.
</Tip>

## Create an event

<Steps>
  <Step title="Gather event details">
    - **Venue ID** from `GET /venues`
    - **Date** (`YYYY-MM-DD`) and **start/end times** (`HH:MM`, 24-hour)
    - **Capacity** and **ticket price** (USD)
    - Guest-facing **description**
  </Step>

  <Step title="Submit the event">
    ```bash
    curl -X POST https://api.kdllc.com/v1/events \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "venue_id": "venue_4f8a2c1e",
        "name": "Valentine'\''s Day Jazz & Dinner",
        "date": "2024-02-14",
        "start_time": "19:00",
        "end_time": "23:00",
        "capacity": 60,
        "ticket_price": 95.00,
        "description": "Live jazz, four-course dinner, champagne welcome."
      }'
    ```

    Save the returned `id`. Events are created in `draft` status.
  </Step>

  <Step title="Publish">
    Update the status to `published` from your KD LLC dashboard to make the event visible to guests.
  </Step>
</Steps>

## Event object fields

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique event identifier |
| `status` | string | `draft`, `published`, or `cancelled` |
| `venue_id` | string | Hosting venue ID |
| `venue_name` | string | Hosting venue name |
| `name` | string | Public-facing event name |
| `date` | string | `YYYY-MM-DD` |
| `start_time` / `end_time` | string | `HH:MM` in venue local time |
| `capacity` | integer | Maximum guests |
| `tickets_sold` | integer | Tickets sold so far |
| `ticket_price` | number | Base price in USD |
| `description` | string | Guest-facing description |
| `created_at` | string | ISO 8601 timestamp |

## Query parameters

`GET /events` supports:

- `venue_id`, `status` (`draft` / `published` / `cancelled`)
- `date_from`, `date_to` for date range
- `page`, `per_page` for pagination (default 20 per page)

<Warning>
  Draft events are not visible to guests. Publish from the dashboard once details are final.
</Warning>
