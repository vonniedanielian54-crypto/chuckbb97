KD LLC gives you a complete toolkit for running special events at your venues. Whether you are hosting an intimate wine tasting, a ticketed rooftop concert, or a private corporate dinner, this guide shows you how to create new events and retrieve event listings through the KD LLC API.

## Prerequisites

- An active KD LLC account with a verified venue
- A valid API key (find yours in the [KD LLC dashboard](https://app.kdllc.com/settings/api))
- At least one venue ID — retrieve yours with `GET /venues`

---

## Listing Events

Retrieve all upcoming events across your venues by calling `GET /events`. Use query parameters to filter by venue, date range, or status.

```bash
curl -X GET "https://api.kdllc.com/v1/events?venue_id=venue_4f8a2c1e&status=published" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json"
```

## Creating an Event

<Steps>
  <Step title="Prepare Your Event Details">
    Before making the API call, gather the following information:

    - **Venue ID** — the `id` of the venue where the event will take place (from `GET /venues`)
    - **Date and times** — the event date in `YYYY-MM-DD` format and start/end times in `HH:MM` (24-hour)
    - **Capacity** — the maximum number of guests
    - **Ticket price** — the base ticket price in USD
    - **Description** — a guest-facing summary of the experience

    <Note>
      Events are created in `draft` status by default, meaning they are not publicly visible until you update the status to `published` through your KD LLC dashboard.
    </Note>
  </Step>

  <Step title="Submit the Event">
    Send a `POST` request to `/events` with your venue details, schedule, capacity, and pricing.

```bash
curl -X POST "https://api.kdllc.com/v1/events" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "venue_id": "venue_4f8a2c1e",
    "name": "Valentine'\''s Day Jazz & Dinner",
    "date": "2024-02-14",
    "start_time": "19:00",
    "end_time": "23:00",
    "capacity": 60,
    "ticket_price": 95.00,
    "description": "An intimate evening of live jazz, a curated four-course dinner, and champagne welcome. Dress code: smart casual."
  }'
```

    **Example response:**

```json
{
  "id": "evt_3a7f1b89",
  "status": "draft",
  "venue_id": "venue_4f8a2c1e",
  "name": "Valentine's Day Jazz & Dinner",
  "date": "2024-02-14",
  "start_time": "19:00",
  "end_time": "23:00",
  "capacity": 60,
  "tickets_sold": 0,
  "ticket_price": 95.00,
  "description": "An intimate evening of live jazz, a curated four-course dinner, and champagne welcome. Dress code: smart casual.",
  "created_at": "2024-01-28T10:05:33Z"
}
```

    Save the returned `id` — you will reference it when looking up this event later with `GET /events`.
  </Step>

  <Step title="Confirm Your Event Is Listed">
    After creating the event, verify it appears in your event listings by calling `GET /events` filtered by its ID or venue:

```bash
curl -X GET "https://api.kdllc.com/v1/events?venue_id=venue_4f8a2c1e" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```

    Once you see your new event in the response, you can publish it and begin managing ticket sales and RSVPs from your KD LLC dashboard.
  </Step>
</Steps>

## Event Object Reference

Every event returned by the API includes the following fields:

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique event identifier |
| `status` | string | `draft`, `published`, or `cancelled` |
| `venue_id` | string | ID of the hosting venue |
| `venue_name` | string | Display name of the hosting venue |
| `name` | string | Public-facing event name |
| `date` | string | Event date in `YYYY-MM-DD` format |
| `start_time` | string | Start time in `HH:MM` (venue local time) |
| `end_time` | string | End time in `HH:MM` (venue local time) |
| `capacity` | integer | Maximum number of guests |
| `tickets_sold` | integer | Number of tickets sold so far |
| `ticket_price` | number | Base ticket price in USD |
| `description` | string | Guest-facing event description |
| `created_at` | string | ISO 8601 timestamp of creation |

## Filtering and Pagination

The `GET /events` endpoint supports several query parameters to help you find the right events:

<AccordionGroup>
  <Accordion title="Filter by venue">
    Use `venue_id` to retrieve only events for a specific location:

```bash
curl -X GET "https://api.kdllc.com/v1/events?venue_id=venue_4f8a2c1e" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```
  </Accordion>

  <Accordion title="Filter by status">
    Use `status` to retrieve events by their publication state (`draft`, `published`, or `cancelled`):

```bash
curl -X GET "https://api.kdllc.com/v1/events?status=published" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```
  </Accordion>

  <Accordion title="Filter by date range">
    Use `date_from` and `date_to` to scope results to a window of dates:

```bash
curl -X GET "https://api.kdllc.com/v1/events?date_from=2024-03-01&date_to=2024-03-31" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```
  </Accordion>

  <Accordion title="Paginate results">
    Use `page` and `per_page` to navigate large result sets. The default is 20 results per page:

```bash
curl -X GET "https://api.kdllc.com/v1/events?page=2&per_page=10" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```
  </Accordion>
</AccordionGroup>

<Warning>
  Events in `draft` status are not visible to guests on the KD LLC platform. Publish your event from the KD LLC dashboard once you have reviewed all details, so guests can discover and register for it.
</Warning>
