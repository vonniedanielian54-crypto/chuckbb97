title: "How to Create and Manage Reservations with KD LLC"
sidebarTitle: "Make a Reservation"

---

Book a reservation in four steps, then modify or cancel it as needed. Pass your API key as a `Bearer` token in the `Authorization` header on every request.

<Steps>
  <Step title="Search for a venue">
    Filter `/venues` by `city` and `type`.

    ```bash
    curl "https://api.kdllc.com/v1/venues?city=New+York&type=restaurant" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    Note the `id` of the venue you want to book.
  </Step>

  <Step title="Retrieve venue details">
    Fetch capacity, hours, timezone, and cancellation policy.

    ```bash
    curl "https://api.kdllc.com/v1/venues/venue_4f8a2c1e" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    <Tip>
      Times are in the venue's local timezone (`timezone` field). Convert to UTC if you store times universally.
    </Tip>
  </Step>

  <Step title="Create the reservation">
    ```bash
    curl -X POST https://api.kdllc.com/v1/reservations \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "venue_id": "venue_4f8a2c1e",
        "date": "2024-02-14",
        "time": "20:00",
        "party_size": 4,
        "guest_name": "Jane Doe",
        "guest_email": "jane.doe@example.com",
        "guest_phone": "+1 (212) 555-0199",
        "notes": "Anniversary dinner"
      }'
    ```

    Store the returned `id` and `confirmation_code` to manage the reservation later.
  </Step>

  <Step title="Receive confirmation">
    KD LLC automatically sends:

    - A **confirmation email** to `guest_email` with date, time, venue, and code
    - A **`reservation.confirmed` webhook** to any endpoint registered in **Settings → Webhooks**
  </Step>
</Steps>

## Manage a reservation

### Retrieve

```bash
curl https://api.kdllc.com/v1/reservations/res_7c2e9d41 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Modify

Send a `PUT` with the full updated body (include unchanged required fields).

```bash
curl -X PUT https://api.kdllc.com/v1/reservations/res_7c2e9d41 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "venue_id": "venue_4f8a2c1e",
    "date": "2024-02-14",
    "time": "19:30",
    "party_size": 6,
    "guest_name": "Jane Doe",
    "guest_email": "jane.doe@example.com",
    "guest_phone": "+1 (212) 555-0199",
    "notes": "Party grew to 6"
  }'
```

### Cancel

```bash
curl -X DELETE https://api.kdllc.com/v1/reservations/res_7c2e9d41 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The guest receives an automatic cancellation email.

<Warning>
  Cancellation policies vary by venue. Check the venue's `cancellation_policy` before cancelling to avoid fees.
</Warning>
