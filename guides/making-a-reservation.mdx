This guide walks you through the full reservation flow on KD LLC — from discovering the right venue and confirming open time slots to submitting your booking and receiving a confirmation. By the end, you will have a confirmed reservation and understand how to modify or cancel it if your plans change.

## Prerequisites

Before you begin, make sure you have the following:

- An active KD LLC account
- A valid API key (find yours in the [KD LLC dashboard](https://app.kdllc.com/settings/api))

Include your API key as a `Bearer` token in the `Authorization` header of every request.

---

## Steps

<Steps>
  <Step title="Search for a Venue">
    Start by querying the `/venues` endpoint to find venues that match your city and type. Use the `city` and `type` query parameters to narrow your results.

    ```bash
    curl -X GET "https://api.kdllc.com/v1/venues?city=New+York&type=restaurant" \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json"
    ```

    **Example response:**

    ```json
    {
      "data": [
        {
          "id": "venue_4f8a2c1e",
          "name": "The Golden Plate",
          "type": "restaurant",
          "city": "New York",
          "address": "142 West 54th Street, New York, NY 10019",
          "cuisine": "Contemporary American",
          "rating": 4.8,
          "capacity": 120,
          "phone": "+1 (212) 555-0182",
          "website": "https://www.thegoldenplate.com"
        },
        {
          "id": "venue_9b3d7f22",
          "name": "Maison Lumière",
          "type": "restaurant",
          "city": "New York",
          "address": "88 Park Avenue, New York, NY 10016",
          "cuisine": "French Bistro",
          "rating": 4.6,
          "capacity": 80,
          "phone": "+1 (212) 555-0374",
          "website": "https://www.maisonlumiere.com"
        }
      ],
      "total": 2,
      "page": 1,
      "per_page": 20
    }
    ```

    Note the `id` of the venue you want to book — you will use it in the next step.
  </Step>

  <Step title="Check Availability">
    Before creating a reservation, verify that your preferred date and party size are available. Pass the venue's `id`, your desired `date` (in `YYYY-MM-DD` format), and `party_size` as query parameters.

    ```bash
    curl -X GET "https://api.kdllc.com/v1/venues/venue_4f8a2c1e/availability?date=2024-02-14&party_size=4" \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json"
    ```

    **Example response:**

    ```json
    {
      "venue_id": "venue_4f8a2c1e",
      "date": "2024-02-14",
      "party_size": 4,
      "available_slots": [
        { "time": "17:00", "available": true },
        { "time": "17:30", "available": true },
        { "time": "18:00", "available": false },
        { "time": "18:30", "available": true },
        { "time": "19:00", "available": false },
        { "time": "19:30", "available": true },
        { "time": "20:00", "available": true },
        { "time": "20:30", "available": true },
        { "time": "21:00", "available": true }
      ]
    }
    ```

    Choose a time slot where `"available": true` and record it for the next step.

    <Tip>
      Dates and times are returned in the venue's local timezone. Check the venue's `timezone` field on its full profile (`GET /venues/{id}`) if you need to convert to UTC.
    </Tip>
  </Step>

  <Step title="Create the Reservation">
    Submit a `POST` request to `/reservations` with the venue, date, time, party size, and guest details. All fields in the example below are required unless noted as optional.

    ```bash
    curl -X POST "https://api.kdllc.com/v1/reservations" \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "venue_id": "venue_4f8a2c1e",
        "date": "2024-02-14",
        "time": "20:00",
        "party_size": 4,
        "guest_name": "Jane Doe",
        "guest_email": "jane.doe@example.com",
        "guest_phone": "+1 (212) 555-0199",
        "notes": "Anniversary dinner — please prepare a small dessert surprise."
      }'
    ```

    **Example confirmation response:**

    ```json
    {
      "id": "res_7c2e9d41",
      "status": "confirmed",
      "venue_id": "venue_4f8a2c1e",
      "venue_name": "The Golden Plate",
      "date": "2024-02-14",
      "time": "20:00",
      "party_size": 4,
      "guest_name": "Jane Doe",
      "guest_email": "jane.doe@example.com",
      "guest_phone": "+1 (212) 555-0199",
      "notes": "Anniversary dinner — please prepare a small dessert surprise.",
      "confirmation_code": "KDLLC-20240214-7C2E",
      "created_at": "2024-01-30T14:22:08Z"
    }
    ```

    Store the `id` and `confirmation_code` — you will need them to manage the reservation later.
  </Step>

  <Step title="Receive Confirmation">
    After a successful `POST /reservations`, KD LLC automatically triggers two notifications:

    - **Confirmation email** — Sent to the `guest_email` address you provided. It includes the reservation date, time, venue address, party size, and the unique `confirmation_code`.
    - **Webhook notification** — If you have registered a webhook endpoint in your KD LLC dashboard, a `reservation.confirmed` event payload is dispatched immediately to your endpoint.

    ```json
    {
      "event": "reservation.confirmed",
      "reservation_id": "res_7c2e9d41",
      "confirmation_code": "KDLLC-20240214-7C2E",
      "timestamp": "2024-01-30T14:22:09Z"
    }
    ```

    <Note>
      To configure webhook endpoints, go to **Settings → Webhooks** in your KD LLC dashboard and add your endpoint URL.
    </Note>
  </Step>
</Steps>

## Managing Your Reservation

### Modify a Reservation

To change the date, time, party size, or notes on an existing reservation, send a `PUT` request with the updated fields. Only include the fields you want to change.

```bash
curl -X PUT "https://api.kdllc.com/v1/reservations/res_7c2e9d41" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "time": "19:30",
    "party_size": 6,
    "notes": "Anniversary dinner — party grew to 6. Please arrange a round table."
  }'
```

A successful update returns the full updated reservation object with `"status": "confirmed"` and a new `updated_at` timestamp.

### Cancel a Reservation

To cancel, send a `DELETE` request with the reservation `id`. The guest receives an automatic cancellation email.

```bash
curl -X DELETE "https://api.kdllc.com/v1/reservations/res_7c2e9d41" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Example response:**

```json
{
  "id": "res_7c2e9d41",
  "status": "cancelled",
  "cancelled_at": "2024-02-10T09:15:00Z"
}
```

<Warning>
  Cancellation policies vary by venue. Some venues enforce a no-cancellation window (e.g., within 24 hours of the reservation). Check the venue's `cancellation_policy` field before cancelling to avoid fees.
</Warning>

---

<Tip>
  Book during **off-peak hours** — typically before 6:30 PM or after 9:00 PM on weekdays — for the widest selection of available time slots. Peak times like Friday and Saturday evenings between 7:00 PM and 9:00 PM fill up quickly, especially at top-rated venues.
</Tip>
