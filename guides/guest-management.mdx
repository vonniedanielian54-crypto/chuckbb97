KD LLC stores detailed profiles for every guest you serve, giving you a single source of truth for dietary needs, seating preferences, VIP status, and visit history. By keeping profiles accurate and up to date, you can deliver consistently personalized experiences — from a preferred window table to a remembered birthday celebration — every time a guest walks through your door.

---

## Creating a Guest Profile

Add a new guest to your KD LLC account by sending a `POST` request to `/guests`. You can capture contact details, dietary restrictions, and general preferences at the time of creation.

```bash
curl -X POST "https://api.kdllc.com/v1/guests" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Doe",
    "email": "jane.doe@example.com",
    "phone": "+1 (212) 555-0199",
    "dietary_restrictions": ["gluten-free", "no shellfish"],
    "vip_status": false,
    "preferences": {
      "seating": "window booth",
      "music": "jazz",
      "special_occasions": ["birthday", "anniversary"]
    }
  }'
```

**Example response:**

```json
{
  "id": "guest_8d4c2f1a",
  "name": "Jane Doe",
  "email": "jane.doe@example.com",
  "phone": "+1 (212) 555-0199",
  "dietary_restrictions": ["gluten-free", "no shellfish"],
  "vip_status": false,
  "visit_count": 0,
  "preferences": {
    "seating": "window booth",
    "music": "jazz",
    "special_occasions": ["birthday", "anniversary"]
  },
  "reservation_history": [],
  "created_at": "2024-01-30T09:11:42Z"
}
```

<Tip>
  Set `vip_status` to `true` at creation time to immediately flag a guest for elevated service across all your venues — no separate update needed.
</Tip>

## Looking Up Guests

Search for guests by email address, name, or phone number using query parameters on `GET /guests`. This is the fastest way to pull up a profile at check-in or when taking a new reservation.

**Search by email:**

```bash
curl -X GET "https://api.kdllc.com/v1/guests?email=jane.doe@example.com" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```

**Example response:**

```json
{
  "data": [
    {
      "id": "guest_8d4c2f1a",
      "name": "Jane Doe",
      "email": "jane.doe@example.com",
      "vip_status": true,
      "visit_count": 14,
      "dietary_restrictions": ["gluten-free", "no shellfish"],
      "preferences": {
        "seating": "window booth",
        "music": "jazz",
        "special_occasions": ["birthday", "anniversary"]
      }
    }
  ],
  "total": 1
}
```

You can also search by `name` or `phone` using the same pattern:

```bash
curl -X GET "https://api.kdllc.com/v1/guests?phone=%2B12125550199" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```

<Note>
  URL-encode special characters when passing query parameters. The `+` in phone numbers should be encoded as `%2B`.
</Note>

  "reservation_history": [
    {

      "date": "2024-02-14",
      "time": "20:00",
      "party_size": 4,
      "status": "completed"
    },
    {
      "reservation_id": "res_2b5f8a03",
      "venue_name": "The Golden Plate",

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique guest identifier |
| `name` | string | Full name |
| `email` | string | Primary contact email |
| `phone` | string | Contact phone number |
| `dietary_restrictions` | array | List of dietary needs or allergies |
| `vip_status` | boolean | Whether the guest is flagged as VIP |
| `visit_count` | integer | Total number of completed visits across all venues |
| `preferences` | object | Seating, ambiance, and occasion preferences |
| `reservation_history` | array | Paginated list of past and upcoming reservations |

## Creating VIP Guests

To flag a guest as VIP from the moment they are added to your system, include `"vip_status": true` in your `POST /guests` request body. VIP status is account-wide — it applies across all venues in your KD LLC account.

```bash
curl -X POST "https://api.kdllc.com/v1/guests" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Marcus Green",
    "email": "marcus.green@example.com",
    "phone": "+1 (212) 555-0374",
    "vip_status": true,
    "dietary_restrictions": ["vegan"],
    "preferences": {
      "seating": "corner booth",
      "notes": "Prefers sparkling water. Regular guest — always books for business dinners."
    }
  }'
```

When `vip_status` is `true`, KD LLC surfaces the following behaviours automatically:

- A **VIP badge** appears next to the guest's name in the reservation management dashboard.
- Front-of-house staff receive a **VIP alert** in the check-in interface when the guest's reservation is upcoming.
- VIP guests are eligible for **priority waitlist placement** when their preferred time slot is fully booked.

## Guest Preferences

Capturing preferences at profile creation time means every team member can deliver a consistent, personalised experience without asking the guest to repeat themselves. The `preferences` object supports the following categories:

<AccordionGroup>
  <Accordion title="Dietary restrictions">
    Store allergies and intolerances in the `dietary_restrictions` array. These automatically surface as alerts on the reservation detail view in your dashboard, ensuring kitchen and floor staff are always informed.

    Example values: `"gluten-free"`, `"vegan"`, `"no shellfish"`, `"nut allergy"`, `"dairy-free"`
  </Accordion>

  <Accordion title="Seating preferences">
    Record the guest's preferred seating location in `preferences.seating`. Staff can see this preference when assigning tables.

    Example values: `"window booth"`, `"corner booth"`, `"bar seating"`, `"outdoor terrace"`, `"private dining room"`
  </Accordion>

  <Accordion title="Special occasions">
    Recording upcoming birthdays or anniversaries in `preferences.special_occasions` lets you proactively offer celebration packages at the time of booking.

    Example values: `"birthday"`, `"anniversary"`, `"graduation"`, `"corporate event"`
  </Accordion>

  <Accordion title="General notes">
    Use `preferences.notes` for free-form details that don't fit other categories — for example, a favourite cocktail, preferred background music, or a note about the guest's business relationship.
  </Accordion>
</AccordionGroup>

## Listing All Guests

Retrieve your full guest list with a `GET` request to `/guests`. Results are paginated — use `page` and `per_page` to navigate large lists.

```bash
curl -X GET "https://api.kdllc.com/v1/guests?page=1&per_page=20" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```

**Example response:**

```json
{
  "data": [
    {
      "id": "guest_8d4c2f1a",
      "name": "Jane Doe",
      "email": "jane.doe@example.com",
      "vip_status": true,
      "visit_count": 14
    },
    {
      "id": "guest_2c7b9e33",
      "name": "Marcus Green",
      "email": "marcus.green@example.com",
      "vip_status": true,
      "visit_count": 7
    }
  ],
  "total": 142,
  "page": 1,
  "per_page": 20
}
```

To filter only VIP guests, add `vip_status=true`:

```bash
curl -X GET "https://api.kdllc.com/v1/guests?vip_status=true" \
  -H "Authorization: Bearer kdllc_sk_live_xxxxxxxxxxxxxxxxxxxx"
```
