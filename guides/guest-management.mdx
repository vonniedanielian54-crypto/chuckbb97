Guest profiles store contact info, dietary needs, seating preferences, VIP status, and visit history, so every team member can deliver a consistent experience.

## Create a guest profile

```bash
curl -X POST https://api.kdllc.com/v1/guests \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Doe",
    "email": "jane.doe@example.com",
    "phone": "+1 (212) 555-0199",
    "dietary_restrictions": ["gluten-free", "no shellfish"],
    "vip_status": false,
    "preferences": {
      "seating": "window booth",
      "special_occasions": ["birthday", "anniversary"]
    }
  }'
```

<Tip>
  Set `vip_status: true` at creation to flag a guest for elevated service across all your venues.
</Tip>

## Look up guests

Search by `email`, `name`, or `phone` on `GET /guests`:

```bash
curl "https://api.kdllc.com/v1/guests?email=jane.doe@example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  URL-encode special characters in query parameters. Encode `+` in phone numbers as `%2B`.
</Note>

## Guest object fields

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique guest identifier |
| `name` | string | Full name |
| `email` | string | Primary contact email |
| `phone` | string | Contact phone number |
| `dietary_restrictions` | array | Dietary needs and allergies |
| `vip_status` | boolean | VIP flag |
| `visit_count` | integer | Completed visits across all venues |
| `preferences` | object | Seating, occasions, and free-form notes |
| `reservation_history` | array | Past and upcoming reservations |

## VIP guests

When `vip_status` is `true`, KD LLC automatically:

- Displays a **VIP badge** in the reservation dashboard
- Sends a **VIP alert** to staff at check-in
- Grants **priority waitlist placement** when preferred slots are full

VIP status applies account-wide across all venues.

## Preferences

The `preferences` object supports:

<AccordionGroup>
  <Accordion title="Dietary restrictions">
    Array of allergies and intolerances. Surfaces as alerts on the reservation detail view.

    Example: `"gluten-free"`, `"vegan"`, `"no shellfish"`, `"nut allergy"`
  </Accordion>

  <Accordion title="Seating preferences">
    Preferred location in `preferences.seating`.

    Example: `"window booth"`, `"bar seating"`, `"outdoor terrace"`, `"private dining room"`
  </Accordion>

  <Accordion title="Special occasions">
    Array in `preferences.special_occasions`. Use to offer celebration packages at booking.

    Example: `"birthday"`, `"anniversary"`, `"graduation"`
  </Accordion>

  <Accordion title="General notes">
    Free-form details in `preferences.notes`, such as a favorite cocktail or business context.
  </Accordion>
</AccordionGroup>

## List guests

```bash
curl "https://api.kdllc.com/v1/guests?page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Filter to VIPs with `vip_status=true`.
