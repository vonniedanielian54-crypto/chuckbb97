KD LLC is a hospitality and venue management platform for restaurants, nightlife venues, and event operators. It combines venue discovery, reservations, event planning, and guest management in one place.

## Key features

<CardGroup cols={2}>
  <Card title="Venue Discovery" icon="location-dot">
    Search venues by type, capacity, and availability.
  </Card>
  <Card title="Reservations" icon="calendar-check">
    Manage bookings, walk-ins, and confirmations from one dashboard.
  </Card>
  <Card title="Event Planning" icon="star">
    Run ticketed or invite-only events end to end.
  </Card>
  <Card title="Guest Management" icon="users">
    Track VIPs, preferences, and guest history.
  </Card>
</CardGroup>
