title: "KD LLC Quickstart: Your First Reservation via API"
sidebarTitle: "Quickstart"
description: "Sign up, generate an API key, and book your first reservation with the KD LLC API in under five minutes."
---

Get from sign-up to a confirmed reservation in four steps.

<Steps>
  <Step title="Create your account">
    Sign up at [app.kdllc.com](https://app.kdllc.com) and verify your email.
  </Step>

  <Step title="Generate an API key">
    Go to **Settings → API Keys → Create New Key**. Copy the key immediately, it's shown only once.

    <Warning>
      Never commit keys to version control. Use `kdllc_sk_test_` keys during development.
    </Warning>
  </Step>

  <Step title="List venues">
    ```bash
    curl https://api.kdllc.com/v1/venues \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Step>

  <Step title="Book a reservation">
    ```bash
    curl -X POST https://api.kdllc.com/v1/reservations \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "venue_id": "venue_01HXYZ1234ABCD",
        "date": "2025-09-15",
        "time": "19:30",
        "party_size": 4,
        "guest_name": "Jane Smith",
        "guest_email": "jane.smith@example.com"
      }'
    ```

    KD LLC sends a confirmation email to the guest automatically.
  </Step>
</Steps>

<Note>
  Explore all endpoints in the [API Reference](/api/overview).
</Note>
