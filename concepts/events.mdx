Events are curated experiences (a NYE dinner, wine tasting, DJ night) with fixed dates, ticket inventory, and guest lists. Reservations book a table; events book a specific experience.

## Event object

| Property | Type | Description |
| --- | --- | --- |
| `id` | string | Unique identifier |
| `venue_id` | string | Hosting venue |
| `name` | string | Display name |
| `description` | string | Guest-facing description |
| `type` | string | `public`, `private`, or `ticketed` |
| `date` | string | `YYYY-MM-DD` |
| `start_time` / `end_time` | string | `HH:MM` (24-hour) |
| `capacity` | integer | Maximum attendees |
| `ticket_price` | number | Base price in USD |
| `ticket_types` | array | Available ticket tiers |
| `status` | string | `draft`, `published`, `sold_out`, `cancelled`, `completed` |

```json
{
  "id": "evt_nye2025",
  "venue_id": "venue_abc123",
  "name": "New Year's Eve Grand Gala",
  "type": "ticketed",
  "date": "2025-12-31",
  "start_time": "20:00",
  "end_time": "02:00",
  "capacity": 150,
  "ticket_price": 175.00,
  "ticket_types": [
    {
      "id": "tt_general",
      "name": "General Admission",
      "price": 175.00,
      "includes": ["dinner", "open_bar", "party_favors"]
    },
    {
      "id": "tt_vip",
      "name": "VIP Table",
      "price": 350.00,
      "includes": ["dinner", "open_bar", "reserved_table", "bottle_service"]
    }
  ],
  "status": "published"
}
```

<Note>
  `end_time` can fall on the next calendar day (e.g., `02:00` for a midnight event).
</Note>

## API

```bash
# List
curl https://api.kdllc.com/v1/events \
  -H "Authorization: Bearer YOUR_API_KEY"

# Create (returns draft status)
curl -X POST https://api.kdllc.com/v1/events \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "venue_id": "venue_abc123",
    "name": "New Year Gala",
    "type": "ticketed",
    "date": "2025-12-31",
    "start_time": "20:00",
    "end_time": "02:00",
    "capacity": 150,
    "ticket_types": [
      {"name": "General", "price": 175.00, "includes": ["dinner", "open_bar"]},
      {"name": "VIP", "price": 350.00, "includes": ["dinner", "open_bar", "reserved_table"]}
    ]
  }'
```

<Tip>
  New events start as `draft`. Update `status` to `published` when ready for guests.
</Tip>

## Events vs. reservations

|  | Reservation | Event |
| --- | --- | --- |
| **Purpose** | Book a table | Book a specific experience |
| **Pricing** | Usually free | Often ticketed |
| **Flexibility** | Guest picks a time | Date and time fixed |
| **Capacity** | Per time slot | Per event |
| **Guest list** | Not applicable | Managed on the event |
| **Modification** | Time and size changeable | Limited; ticket transfers may apply |

## Event types

- **Public** — Open to all guests, appears in search
- **Private** — Invite-only, accessed via direct link or guest list
- **Ticketed** — Requires purchase; guests added to guest list automatically

<Warning>
  Private event links are shareable. To strictly restrict attendance, use the guest list and disable open registration.
</Warning>

## Guest lists

Every event has a guest list: the source of truth for check-in and capacity. Each entry includes name and contact, ticket type, check-in status, and party size.

Guests are added automatically on ticket purchase (ticketed) or RSVP approval (RSVP-based). Use `GET /events/{id}/guests` for a live attendee count, check-in sheet, or check-in updates.
