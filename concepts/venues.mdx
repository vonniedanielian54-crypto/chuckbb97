Venues are the foundation of KD LLC. Every reservation, event, and guest interaction starts with a venue.

## Venue types

| Type | Description |
|---|---|
| `restaurant` | Full-service dining |
| `bar` | Cocktail bars, sports bars, taprooms |
| `lounge` | Upscale lounges and social spaces |
| `club` | Nightclubs and dance venues |
| `event-space` | Private dining and event rooms |

## Venue object

| Property | Type | Description |
|---|---|---|
| `id` | string | Unique identifier |
| `name` | string | Display name |
| `type` | string | Venue category |
| `address` | object | Street, city, state, ZIP |
| `capacity` | integer | Maximum guests |
| `cuisine` | string | Primary cuisine or food style |
| `hours` | object | Operating hours by day |
| `amenities` | array | Available amenities |
| `contact` | object | Phone, email, website |

```json
{
  "id": "venue_abc123",
  "name": "The Grand Lounge",
  "type": "lounge",
  "address": {
    "street": "123 Fifth Avenue",
    "city": "New York",
    "state": "NY",
    "zip": "10001"
  },
  "capacity": 200,
  "cuisine": "Contemporary American",
  "hours": {
    "monday": "5pm-2am",
    "friday": "5pm-4am",
    "saturday": "5pm-4am"
  },
  "amenities": ["valet", "private_dining", "full_bar"],
  "contact": {
    "phone": "+12125550100",
    "email": "reservations@thegrandlounge.com",
    "website": "https://thegrandlounge.com"
  }
}
```

<Note>
  Days omitted from `hours` mean the venue is closed that day.
</Note>

## Fetching venues

```bash
# List
curl https://api.kdllc.com/v1/venues \
  -H "Authorization: Bearer YOUR_API_KEY"

# Single venue
curl https://api.kdllc.com/v1/venues/venue_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Availability

Check open time slots before booking. Provide:

- `venue_id`
- `date` (`YYYY-MM-DD`)
- `party_size`
- Optional time preference (e.g., `"evening"` or `"7:30pm"`)

Only slots returned in an availability response can be booked.

## Searching and filtering

Combine query parameters on `GET /venues`:

- `type`, `city`, `cuisine`
- `capacity` (min/max)
- `amenities` (e.g., `valet`, `private_dining`)
- `date` + `party_size` to return only venues with availability

```bash
curl "https://api.kdllc.com/v1/venues?type=restaurant&city=New+York&cuisine=Italian" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Warning>
  Venue data changes. Fetch fresh venue details before presenting them to guests rather than relying on cached results.
</Warning>
